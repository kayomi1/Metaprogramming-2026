# L02 Самостійна робота: Основи `C#`

## Запуск

Усі команди виконуються з папки `L02_SelfWork`.

```cmd
dotnet build
dotnet run --project Task01
dotnet run --project Task02
dotnet run --project Task03
dotnet run --project Task04
dotnet run --project Task05
dotnet run --project Task06
dotnet run --project Task07
dotnet run --project Task07 -- --seed
```

Аргумент `--seed` у Task07 додає три демонстраційні записи.
