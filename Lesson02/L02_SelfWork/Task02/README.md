# Task02. Контроль доступу до події

Програма перевіряє, чи може відвідувач потрапити на подію, і визначає його категорію.

## Запуск

```cmd
dotnet run --project Task02
```

## Правила перевірки (у такому порядку)

1. Обліковий запис заблоковано → відмова.
2. Немає квитка → відмова.
3. Вік до 14 років без дорослого → відмова.
4. Подія о 22:00 або пізніше для осіб молодше 18 років → відмова.

Категорія: дитина (0–13), підліток (14–17), дорослий (18–64), старша особа (65+).

Діапазони: вік 0–120, година 0–23.

## Контрольні набори

| № | Вхід (вік; година; квиток; блокування; супровід) | Очікуваний результат |
| --- | --- | --- |
| 1 | 13; 15; так; ні; ні | Доступ заборонено: вік до 14 років без дорослого |
| 2 | 14; 15; так; ні; ні | Доступ дозволено. Категорія: підліток. |
| 3 | 17; 22; так; ні; ні | Доступ заборонено: подія о 22:00 або пізніше |
| 4 | 64; 12; так; ні; ні | Доступ дозволено. Категорія: дорослий. |
| 5 | 30; 12; ні; так; ні | Доступ заборонено: обліковий запис заблоковано |
| 6 | 150; 12; так; ні; ні | Помилка: вік поза діапазоном, програма питає знову |
