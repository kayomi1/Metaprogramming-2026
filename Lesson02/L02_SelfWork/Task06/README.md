# Task06. Рекурсивна лабораторія чисел

Програма реалізує три рекурсивні алгоритми для невід'ємних цілих чисел і порівнює рекурсивний НСД з ітеративним.

## Запуск

```cmd
dotnet run --project Task06
```

## Алгоритми

- **SumDigits(n)** — сума цифр. Базовий випадок: `n < 10`, повертає `n`. Крок: остання цифра + сума решти (`n / 10`).
- **ToBinary(n)** — двійкове представлення без `Convert.ToString` і без циклів. Базовий випадок: `n < 2`. Крок: `ToBinary(n / 2)` + остання цифра.
- **Gcd(a, b)** — НСД за алгоритмом Евкліда. Базовий випадок: `b == 0`, результат `a`. Крок: `Gcd(b, a % b)`.
- **GcdIterative(a, b)** — ітеративна версія НСД для порівняння.

Рекурсія завершується, бо на кожному кроці аргумент зменшується: `n / 10`, `n / 2` і `a % b` менші за вхідні значення, тому рано чи пізно досягається базовий випадок. Межа введення 0–1 000 000 000.

## Контрольні набори

| № | Вхід | Очікуваний результат |
| --- | --- | --- |
| 1 | n = 42 | Сума цифр 6, двійкове `101010` |
| 2 | n = 0 | Сума цифр 0, двійкове `0` |
| 3 | n = 1000000000 | Сума цифр 1, двійкове `111011100110101100101000000000` |
| 4 | НСД(84, 30) | 6 (рекурсія і ітерація однакові) |
| 5 | НСД(0, 9) | 9 |
| 6 | НСД(17, 5) | 1 |
| 8 | НСД(1071, 462) | 21 |
| 9 | n = -1 | Помилка діапазону, програма питає знову |
