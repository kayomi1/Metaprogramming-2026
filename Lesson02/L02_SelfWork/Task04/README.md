# Task04. Схема місць у кінозалі

Програма показує зал як таблицю, дозволяє бронювати та скасовувати місця і виводить статистику.

## Запуск

```cmd
dotnet run --project Task04
```

## Позначення

- `[.]` — місце вільне;
- `[X]` — місце заброньоване.

Ряди та місця користувач вводить з номера 1, а програма переводить їх в індекси масиву з 0.

Розміри: рядів від 3 до 10, місць у ряду від 4 до 12.

## Контрольні набори

Для тестів використовував зал 3×4.

| № | Дії | Очікуваний результат |
| --- | --- | --- |
| 1 | Бронювання: ряд 1, місце 1 | Місце заброньовано |
| 2 | Бронювання: ряд 1, місце 1 (повторно) | `Це місце вже заброньовано.` |
| 3 | Скасування: ряд 2, місце 3 (вільне) | `Це місце вже вільне, скасовувати нічого.` |
| 4 | Ряд 0 або ряд 4 | Помилка діапазону, програма питає знову |
| 5 | Пункт меню `9` | `Такого пункту немає.` |
