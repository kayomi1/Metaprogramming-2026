# Task07. Консольний облік витрат

Програма зберігає витрати поточного сеансу в списку `List<Expense>`.

## Запуск

```cmd
dotnet run --project Task07
dotnet run --project Task07 -- --seed
```

Аргумент `--seed` додає три демонстраційні записи і показує приклад копіювання record через `with`.

## Структура файлів

- `Expense.cs` — enum `ExpenseCategory` і record `Expense`;
- `ExpenseStore.cs` — клас зберігання: додавання, пошук і видалення за Id;
- `Program.cs` — меню та методи для кожного пункту.

## Меню

1. Додати витрату (дата, сума, категорія, опис);
2. Показати всі;
3. Фільтр за категорією;
4. Видалити за Id;
5. Звіт (загальна сума, середня, найбільша, суми за категоріями);
6. Завершити.

Повідомлення мають різні кольори: Info (блакитний), Success (зелений), Warning (жовтий), Error (червоний).

## Контрольні набори

| № | Дія | Очікуваний результат |
| --- | --- | --- |
| 1 | Запуск з `--seed` | 3 записи, загальна сума 1 245,50 грн |
| 2 | Звіт після `--seed` | Сума 1 245,50; середня 415,17; найбільша 775,00 |
| 3 | Дата `25.10.2026`, сума `200`, категорія 1, опис `Кава` | `Додано витрату #4` |
| 4 | Сума `-5` або `0` | Помилка, програма питає знову |
| 5 | Порожній опис | Помилка, програма питає знову |
| 6 | Видалити Id `99` | Попередження, програма працює далі |
| 7 | Звіт при порожньому списку | `Звіт порожній: записів немає.` без помилки ділення |
