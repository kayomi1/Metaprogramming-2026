# Task03. Статистика числової послідовності

Програма запитує кількість чисел (від 5 до 100), потім самі числа, і виводить статистичний звіт.

## Запуск

```cmd
dotnet run --project Task03
```

## Що виводиться

- початковий масив і відсортована копія;
- мінімум, максимум, сума, середнє;
- кількість додатних, від'ємних і нульових елементів;
- кількість парних, непарних і унікальних значень.

## Контрольні набори

| № | Вхід (числа) | Очікуваний результат |
| --- | --- | --- |
| 1 | N=6: `4, -2, 4, 0, 7, -2` | Мін -2, макс 7, сума 11, середнє 1.83, унікальних 4, відсортована `[-2, -2, 0, 4, 4, 7]` |
| 2 | N=5: `0, 0, 0, 0, 0` | Мін 0, макс 0, сума 0, нульових 5, унікальних 1 |
| 3 | N=3 | Повідомлення: кількість має бути від 5 до 100 |
| 4 | N=5, другий елемент `abc` | Повідомлення про помилку, програма питає знову |
