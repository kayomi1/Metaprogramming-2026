# Task01. Конвертер температор

Програма переводить температуру між шкалами Цельсія (C), Фаренгейта (F) і Кельвіна (K).

## Запуск

```cmd
dotnet run --project Task01
```

## Як працює

1. Користувач вводить число та початкову одиницю. Якщо температура нижча за абсолютний нуль, програма питає знову.
2. Вводиться одиниця результату.
3. Перетворення відбувається через Кельвіни. Якщо одиниці однакові, значення не змінюється.
4. Одиниці приймаються без урахування регістру (`c`, `C`).

Абсолютний нуль: -273.15 C, -459.67 F, 0 K.

## Контрольні набори

| № | Вхід | Очікуваний результат |
| --- | --- | --- |
| 1 | `100`, `C`, `F` | `Результат: 100.00 C = 212.00 F` |
| 2 | `0`, `C`, `K` | `Результат: 0.00 C = 273.15 K` |
| 3 | `32`, `F`, `C` | `Результат: 32.00 F = 0.00 C` |
| 4 | `-500`, `C` | Помилка абсолютного нуля, програма питає знову |
| 5 | `abc` | Помилка введення числа, програма питає знову |
| 6 | `10`, `X` | Помилка: допустимі C, F, K |
